# Anciens designs — conservés pour référence

Ces dix fichiers sont les premières fiches excursion, une par marque
(Notion, Claude, Apple, Airbnb, Slack, Nike, Mastercard, ElevenLabs, Clay,
Airtable). Chacun embarquait sa propre copie du texte de la fiche, ce qui
obligeait à corriger dix fois la même phrase.

Ils ne sont plus branchés sur la galerie. La fiche vit désormais dans
`../fiche.html` (un seul markup) avec une feuille de style par variation
dans `../styles/`. On les garde ici parce qu'ils restent la source des
ingrédients repris dans les six variations :

| Ancien style | Ce qui en a été retenu | Variation |
|---|---|---|
| Notion | la bordure gauche comme seul marqueur de bloc | `rule` |
| Slack / Nike | l'organisation du bandeau titre, photo comprise | `banner` |
| Mastercard | les portraits de villes sur le fil de l'itinéraire | `portrait` |
| Airtable | le motif qui court à gauche de tout l'itinéraire | `pattern` |
| Claude | les blocs Bus en noir, ici réchauffé et adouci | `ink` |
| Clay | l'itinéraire lu comme une pile de tuiles | `bento` |

Chacun s'ouvre encore directement dans un navigateur.
