Vous êtes designer & dev créant un site web portfolio pour **UpTempo**, un guide touristique freelance spécialisé en journeys éducatifs. Le site doit :
- Montrer les services (excursions, formations, guidance)
- Être engageant, avec beaucoup de visuels et icônes
- Permettre de **switcher entre plusieurs design systems** via une navbar horizontale

### **Objectif principal**
Créer un site web responsif, single-page, qui présente UpTempo et ses services. Le site doit avoir un **design system switcher** en haut : chaque clique applique un style différent au MÊME site web, sans rechargement.

---

### **Architecture du design switcher**

#### **1. Barre de navigation fixe (top)**
- Position sticky/fixed, toujours visible
- À gauche : logo UpTempo (mark + wordmark)
- Au centre ou à droite : boutons de style (Design 1, Design 2, Design 3, etc.)
- Exemple : `[UpTempo] ⋯ [Notion] [Editorial] [Dark]`
- Chaque clic applique instantanément les tokens CSS (couleurs, typo, spacing) de ce style

#### **2. Système de tokens CSS**
Créer au minimum **3 design systems** distincts, stockés en JS/CSS :
- **Design 1 (Notion) :** bleu primaire #0075de, canvas soft #f6f5f4, Inter, style Notion exact
- **Design 2 (Warm/Editorial) :** palette terracotta/crème, serif + sans-serif, espaces larges, vibe magazine haut de gamme
- **Design 3 (Dark/Modern) :** fond sombre (presque noir), accents vibrants (vert acid, rose, cyan), typo moderne, micro-interactions

Chaque design doit redéfinir via CSS custom properties :
- `--primary`, `--secondary`, `--accent`
- `--canvas`, `--canvas-soft`, `--surface`
- `--ink`, `--ink-muted`, `--hairline`
- `--font-display`, `--font-body`, `--font-mono`
- `--radius`, `--shadow`

### **Interactions & UX**

#### **Design Switcher**
- Navbar avec boutons nommés (ex. "Notion", "Editorial", "Dark")
- Au clic : 
  - Appliquer le nouveau design system (CSS custom properties)
  - Smooth transition (0.3–0.5s fade ou no-flash)
  - Sauvegarder le choix en `localStorage` (optionnel, pour persistance)
  - Indiquer le style actif (underline, bold, colored pill, etc.)

#### **Scroll animations**
- Subtle fade-in on scroll pour les sections (IntersectionObserver)
- Cards qui stagger-entrent en view
- Pas de distraction, juste du polish

#### **Responsive**
- Desktop : full navbar, multi-column grids, large images
- Tablet : navbar collapse à hamburger (optionnel), grids 2-up → 1-up
- Mobile : single column, navbar simplifiée, images redimensionnées

### **Code structure (recommandé)**

```
<html>
  <head>
    <!-- Fonts, meta, base styles -->
    <!-- CSS custom properties (default design) -->
  </head>
  <body>
    <!-- Navbar avec design switcher -->
    <nav class="navbar">
      <div class="logo">UpTempo</div>
      <div class="design-switcher">
        <button data-design="notion" class="active">Notion</button>
        <button data-design="editorial">Editorial</button>
        <button data-design="dark">Dark</button>
      </div>
    </nav>

    <!-- Main content (same HTML for all designs) -->
    <section class="hero">...</section>
    <section class="philosophy">...</section>
    <section class="services">...</section>
    <section class="journey-featured">...</section>
    <section class="guide">...</section>
    <section class="methods">...</section>
    <section class="formats">...</section>
    <section class="cta">...</section>
    <footer>...</footer>

    <script>
      // Design system definitions (DESIGN_SYSTEMS object)
      // Design switcher logic (applyDesign() function)
      // Animations (IntersectionObserver, etc.)
    </script>
  </body>
</html>
```

### **Design Systems à créer (au minimum)**

**Design 1 : "Notion" (ce que vous avez déjà)**
- Primary: #0075de
- Canvas-soft: #f6f5f4
- Font: Inter
- Spacing: Notion scale (generous)
- Radius: Notion (soft 12px)

**Design 2 : "Editorial / Warm"**
- Primary: #c97c3c (terracotta)
- Secondary: #1a1612 (near-black)
- Canvas: #fef9f3 (cream/off-white)
- Font-display: serif (Georgia, Playfair, etc.)
- Font-body: sans-serif classique (Helvetica Neue, etc.)
- Spacing: generous margins, luxury magazine feel
- Radius: mostly square (2px) with select rounded buttons (20px)
- Shadow: richer, more classical

**Design 3 : "Dark / Modern"**
- Background: #0f0f0f (nearly black)
- Primary: #00ff88 (acid green) or #ff0080 (hot pink)
- Secondary: #00d9ff (cyan)
- Font: modern geometric sans (DM Sans, Inter variant, or Outfit)
- Spacing: tight, modern, minimal
- Radius: 8px–16px, consistent
- Shadow: neon-like glows (optional, subtle)
