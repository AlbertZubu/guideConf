# shadcn/ui Design Skill

## Objectif

Créer des interfaces :

- élégantes et professionnelles ;
- accessibles et responsives ;
- visuellement cohérentes ;
- simples à comprendre ;
- réalistes et prêtes pour la production ;
- construites avec shadcn/ui plutôt qu’avec des composants improvisés.

Ce skill ne doit pas seulement produire une interface techniquement correcte.

Il doit améliorer :

- la hiérarchie visuelle ;
- la composition ;
- les proportions ;
- les espacements ;
- la typographie ;
- le rythme de la page ;
- la cohérence graphique ;
- la clarté des appels à l’action.

---

# 1. Inspecter le projet avant de coder

Avant toute modification importante :

1. Identifier le framework utilisé.
2. Identifier la version de Tailwind CSS.
3. Vérifier si shadcn/ui est déjà configuré.
4. Lire `components.json` s’il existe.
5. Identifier les composants déjà présents dans `components/ui`.
6. Identifier les couleurs, variables CSS, polices et rayons déjà utilisés.
7. Réutiliser le design system existant avant d’en créer un nouveau.
8. Ne jamais réinitialiser automatiquement une configuration shadcn existante.

Quand shadcn/ui est installé, utiliser si nécessaire :

- `npx shadcn@latest info`
- `npx shadcn@latest docs`
- `npx shadcn@latest docs button`
- `npx shadcn@latest docs card`

Adapter le gestionnaire de paquets au projet : npm, pnpm.
